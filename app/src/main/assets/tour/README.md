# 차량 조작 둘러보기 이미지 (아이오닉 5)

이 폴더에 `<항목 id>.png` 또는 `.jpg`를 넣으면 둘러보기 행을 펼쳤을 때 본문 위에 16:9로 표시된다. 파일이 없는 항목은 글만 나온다.

| 파일명 | 항목 | 찍을 것 |
|---|---|---|
| `ctrl_start` | 시동 | 핸들 오른쪽 시동 버튼 + 계기판 READY |
| `ctrl_gear` | 기어 (컬럼 레버) | 핸들 오른쪽 아래 변속 레버, 끝의 P 버튼 |
| `ctrl_parking_brake` | 주차 브레이크 | 핸들 왼쪽 아래 P 스위치, 콘솔 AUTO HOLD |
| `ctrl_regen` | 회생제동 패들 | 핸들 뒤 양쪽 패들 |
| `ctrl_wiper` | 와이퍼·워셔 | 오른쪽 위 레버 |
| `ctrl_lights` | 전조등 | 왼쪽 레버 끝 링(AUTO) |
| `ctrl_charge_port` | 충전구 | 뒷좌석 오른쪽 뒤 펜더, 열린 상태 |
| `ctrl_hipass` | 하이패스 | 룸미러 카드 슬롯 |

권장: 1280×720 이상, 16:9. 항목 id는 `data/Guides.kt`의 `controls`와 같다.
